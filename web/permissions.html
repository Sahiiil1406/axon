03 · demo beats

Run the budget violation.

beat 1 · human vs agent

On the demo page, call increment() as humanCall and then as agentCall. Both hit the same counter endpoint; the human adds 1 through an ordinary EOA transaction, the agent adds 10 through a VERIFY + SENDER frame transaction.

beat 2 · budget violation

Set the budget just below an amount you want to block (for example 0.001 ETH), then call payAmount(uint256) as the agent with a larger amount such as 0.05 ETH. The call is rejected with E_EPOCH_BUDGET. Raise the budget to 0.5 ETH, call the same amount again, and it passes.
